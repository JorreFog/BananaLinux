Under the hood

A whole Linux in a few tens of megabytes.

  • Built with Buildroot. A mainline kernel, busybox init and one program on the panels. No systemd, no compositor, no desktop.
  • Read-only and unbreakable. The system is a squashfs; your games, saves and settings live on an exFAT partition any computer can open.
  • Boots straight to the menu. No module loading, no initramfs: the menu starts as soon as the data partition is mounted.
  • Out of the way. The menu sleeps between frames and closes everything while a game runs: the game has the handheld to itself.
  • Two system slots. Updates install beside the running version; the one before is a restart away.
