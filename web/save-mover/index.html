BANANAOS Save Mover

Bring your game saves from GammaOS (or any other handheld) to BananaOS. Drop the files in, keep a backup of the originals, and get one zip laid out exactly like the BananaOS card. Nothing leaves this browser.

Example loaded · add your own saves below

1Add your saves

Copy the save folders off the GammaOS device first (USB, or its SD card in a computer), then drop them here. Whole folders are fine: save states, pictures and settings in them are left out.

2Check where each save goes

BananaOS finds a save by the game's file name. A save called Pokemon - HeartGold Version (USA).sav belongs to Pokemon - HeartGold Version (USA).nds (or .zip). Untick anything you don't want to bring.

ExampleThese rows show what the tool does. They disappear when you add your own saves and never go into a download.

3Back up the originals

Saves the files exactly as you added them, untouched, with a checksum list. Keep this zip until you have played each game on BananaOS. The next step unlocks after this.

Add your own saves first.

4Make the BananaOS pack

Converts the saves (DeSmuME footers cut off, RetroArch saves named .srm) into a zip with the card's own folders. It carries a second copy of the originals in banana/save-backups, so the card keeps one too.

Save the backup first.

5Put it on the handheld

Card in a computer
  1. Open the drive called BANANA.
  2. Copy the saves folder there to your computer first, in case you had saves on BananaOS already.
  3. Unzip the pack and copy its saves and banana folders onto the drive. Merge folders and replace files when asked.
Over Wi-Fi
  1. On the handheld: Settings › Network › File sharing on.
  2. Windows: open \\<address>\banana. Mac: smb://<address>/banana. The address is shown in Settings › Network.
  3. Copy the pack's saves and banana folders in, the same as above.
Then play
  1. Start the game from the menu and use Continue in the game.
  2. DS saves work in both BananaDS and DraStic: BananaOS copies the newer one across when a game starts.
  3. Save states never carry over between emulators. Save in-game on GammaOS before you move.
